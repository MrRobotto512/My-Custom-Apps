Windows Health — drivers, firmware & AI analysis

Reads the customer's Windows without booting it: which Windows and whether it is still supported, how old the BIOS is, and every GPU / chipset / firmware / storage / network driver with its version and date — flagged when it is behind. Then the AI reads the event logs together with that inventory and writes the plain-English diagnosis and update list.
Drivers & firmware
Age is only a hint — an old date does not mean a newer driver exists (vendors stop shipping them). Check online asks Windows Update's catalog for each device's hardware ID and LVFS for this machine's firmware; "update available" is only ever said when a newer version is actually listed.

Windows Migration — clone to a new drive

Clone the internal Windows disk onto a drive plugged in via USB / an enclosure (the customer's new SSD). A drive at least as large gets a full block clone (layout + boot preserved, BitLocker stays encrypted). A smaller drive that still fits the used data is handled by shrinking Windows and copying it file-by-file, then rebuilding the boot. The source is only ever read.

Fresh Windows Install — from an ISO on the stick

Drop Windows 10.iso / Windows 11.iso on the BenchDiag stick. BenchDiag partitions the target, applies the edition and writes the UEFI boot files. The target drive is fully erased.
